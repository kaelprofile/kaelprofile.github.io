■ 파일 구조
─────────────────────────────────────────────
카엘 리드/
├── index.html      ← 메인 HTML 파일
├── styles.css      ← 스타일시트
├── script.js       ← JavaScript (인터랙션)
├── 카엘 브금.mp3    ← BGM 파일
├── 카엘 썸네일.gif  ← 메인 썸네일 이미지
├── images/
│   ├── sfw/        ← 일반 갤러리 이미지
│   └── nsfw/       ← 성인 갤러리 이미지
└── README.txt      ← 이 파일


■ GitHub Pages로 호스팅하기
─────────────────────────────────────────────
1. GitHub에서 새 repository 생성
   - 이름: username.github.io 또는 원하는 이름
   
2. 모든 파일 업로드
   - index.html, styles.css, script.js
   - 카엘 브금.mp3, 카엘 썸네일.gif
   - images 폴더
   
3. Settings → Pages에서 활성화
   - Source: Deploy from a branch
   - Branch: main (또는 master)
   - 폴더: / (root)
   
4. 몇 분 후 https://username.github.io 에서 확인


■ 갤러리에 이미지 추가하기
─────────────────────────────────────────────
1. SFW (일반) 이미지:
   - images/sfw/ 폴더에 이미지 파일 넣기
   - script.js 열기
   - GALLERY_CONFIG.sfw 배열에 파일명 추가:
     
     sfw: [
         'image1.png',
         'image2.jpg',
         'portrait.webp'
     ],

2. NSFW (성인) 이미지:
   - images/nsfw/ 폴더에 이미지 파일 넣기
   - script.js 열기
   - GALLERY_CONFIG.nsfw 배열에 파일명 추가:
     
     nsfw: [
         'nsfw1.png',
         'nsfw2.jpg'
     ],

※ 지원 형식: PNG, JPG, JPEG, GIF, WEBP


■ 휴대폰 비밀번호
─────────────────────────────────────────────
기본 비밀번호: 0218 (카엘의 생일)

변경하려면 script.js에서 다음 줄을 수정:
const correctPin = '0218';


■ BGM 파일 변경
─────────────────────────────────────────────
1. 새 MP3 파일을 같은 폴더에 넣기
2. index.html에서 다음 부분 수정:
   <source src="새파일명.mp3" type="audio/mpeg">

─────────────────────────────────────────────

■ 문제 해결
─────────────────────────────────────────────
Q: BGM이 재생되지 않아요
A: 브라우저 정책상 사용자가 먼저 버튼을 클릭해야 합니다.
   우측 하단 ♪ 버튼을 클릭하세요.

Q: 이미지가 안 보여요
A: 파일 경로와 GALLERY_CONFIG 설정을 확인하세요.

Q: 모바일에서 메뉴가 안 열려요
A: 좌측 상단 햄버거 버튼(≡)을 탭하세요.
